WHY THE FIX FAILED
-------------------------------------------------------------------------------

The CSS change from:
  width: 100%; height: 100%;
To:
  width: auto; height: auto; max-width: 100%; max-height: 100%;

Did NOT work because:

1. Grid container context: display: grid; place-items: center; causes 
   percentage-based max-width/max-height to calculate incorrectly

2. Padding interference: The 24px padding creates a nested sizing context
   where 100% refers to the grid item, not the padded inner area

3. The image still renders at full intrinsic dimensions constrained only
   by width, causing tall images to exceed the square container
