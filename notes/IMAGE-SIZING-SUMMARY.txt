-------------------------------------------------------------------------------
ROOT CAUSE
-------------------------------------------------------------------------------

The CSS rule for .gal-main img uses width:100% and height:100%, which causes
images with tall (portrait) aspect ratios to overflow the container despite
the max-height:100% and object-fit:contain rules.

Current CSS (docs/pages.css line 136):
  .gal-main img {
    width: 100%;
    height: 100%;         ← This is the problem
    object-fit: contain;
    max-height: 100%;
  }

The media query attempts to fix this with !important rules, but it's not
sufficient for all aspect ratios:
  @media (max-width:639px) {
    .gal-main img {
      max-width: 100%!important;
      max-height: 100%!important;
      width: auto!important;      ← These should work but don't
      height: auto!important;     ← in all cases
      object-fit: contain!important;
    }
  }

-------------------------------------------------------------------------------
RECOMMENDED FIX
-------------------------------------------------------------------------------

Update the base .gal-main img rule to use auto dimensions:

.gal-main img {
  max-width: 100%;
  max-height: 100%;
  width: auto;
  height: auto;
  object-fit: contain;
}

This ensures images scale proportionally without exceeding container bounds.

-------------------------------------------------------------------------------
IMPACT
-------------------------------------------------------------------------------

Products with tall product images (portrait orientation) display incorrectly
on mobile devices:
- Image overflows visible container
- Inconsistent design presentation
- Poor user experience

Affected products need to be identified and tested after CSS fix.
